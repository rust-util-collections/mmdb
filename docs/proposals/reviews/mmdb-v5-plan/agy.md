### Ranked Pre-Implementation Edits

1. **Fix invalid baselines, missing budgets, and observer bias in profiling**
   - **Target:** `## 4. Measure the limiting engine operation`, `## 2. Account for the memory that MMDB can observe`, `## Self-test and handoff`; `main` ([v5_profile.rs](../../../../benches/v5_profile.rs#L25-L83)), [runs.csv](../../../benchmarks/point-ops/runs.csv), `DB::get_property` ([db.rs](../../../../src/db.rs#L2075-L2168)), `DbStats` ([stats.rs](../../../../src/stats.rs#L9-L29)).
   - **Hypothesis:** A 16-DB profile selects queue/buffer sizing within a memory ceiling and attributes write p99 without lock-sampling bias.
   - **Baseline/control:** [v5_profile.rs](../../../../benches/v5_profile.rs#L29-L82) confounds `VmHWM` with preload, a 64 MiB default cache, and 1.28 MiB `Vec<u128>` buffers; [runs.csv](../../../benchmarks/point-ops/runs.csv) used `Btrfs compress=zstd:3` with zero flushes. Run fresh-process uninstrumented baselines at `8aacd0f` on an uncompressed FS with 1-writer/warm-`get_pinned` controls; build the missing 16-DB open/closed-loop driver, stage/stall/cold-byte counters, and lock-free Unit 2 gauges (`get_property` locks `DB::inner`, biasing leadership; reconcile Moka `Vec::capacity` vs `pinned_bytes` `Vec::len`).
   - **Test & rule:** Preallocate histograms, read `/proc/self/statm` RSS post-preload, and place cold L1 prefixes *outside* the hot pair (`overlapping_files_for_inputs` in [leveled.rs](../../../../src/compaction/leveled.rs#L212-L247) spans `[min, max]`, confounding `sync_wal()` vs 1-byte deletes on interior gaps). Set **planning budgets** (not empirical results): `<=512 MiB` memtables+pins across 16 DBs with a `256 MiB` `BlockCachePool` (2 GiB split in [mmdb.rs](https://github.com/rust-util-collections/vsdb/blob/9712c0ea89b6b79d31c8e89ba75e235a16bbe8d3/core/src/common/engine/mmdb.rs#L1468-L1503)), `<=3%` instrumentation drift, and `>=20%` leader-time share for both WAL and apply (`W+A->max(W,A)` caps gain `<1.25x`). **Pass** profiles within budget beating `depth=1` p99 beyond 5-pair IQR; **defer** overlap below `20%`.

2. **Eliminate the mixed-group `no_slowdown` stall and false pass**
   - **Target:** `## 1. Make write pressure retryable`; `write_batch_inner`, `enqueue_write`, `write_batch_group` ([db.rs](../../../../src/db.rs#L2900-L3114)); `test_write_options_no_slowdown` ([integration.rs](../../../../tests/integration.rs#L780-L805)).
   - **Hypothesis:** `no_slowdown` returns `ErrorKind::Busy` without waiting on flush/compaction I/O, even in mixed write groups.
   - **Baseline/control:** `test_write_options_no_slowdown` covers only single-writer `l0_slowdown_trigger(3)`; malformed-batch `InvalidArgument` checks are controls. Preserving `write_batch_group`'s check ([db.rs](../../../../src/db.rs#L3091-L3113)) sets `Err(Busy)` without `done=true` (or blocks a `no_slowdown` leader at line 3111) on `FlushQueue::check_capacity(..., false)`.
   - **Test & rule:** Return `Error::busy` at [db.rs](../../../../src/db.rs#L2912) and wake/hand off rejected `no_slowdown` entries before `check_capacity(..., false)`. Build L0-stop and parked-flush (`FlushQueue::on_next_build`) mixed-group tests. **Pass** only if `no_slowdown` returns `Busy` within a `100 ms` **planning timeout** (vs `10 s` park) while flush stays parked, `.wal` length and `snapshot_seq` stay unchanged, and the neighbor commits after unparking; **fail** otherwise.

3. **Replace the L0 sub-compaction false-pass gate and cap cross-DB workers**
   - **Target:** `## 5. Promote only the candidates supported by the profiles`, `## Self-test and handoff`; `execute_compaction_io`, `build_sub_tasks`, `test_execute_compaction_io_actually_parallelizes_with_max_subcompactions` ([leveled.rs](../../../../src/compaction/leveled.rs#L1184-L1243)).
   - **Hypothesis:** Splitting `L0->L1` at L1 boundaries lowers L0 stalls and write p99 without oversubscribing multi-DB hosts.
   - **Baseline/control:** That self-test is a **false pass** (`L1->L2` only; `execute_compaction_io` hardcodes `task.level==0` to `1`), `build_sub_tasks` ([leveled.rs](../../../../src/compaction/leveled.rs#L414-L434)) clones point-disjoint L0 SSTs into every sub-task, and `thread::scope` lacks a cross-DB cap (`16*max_subcompactions` threads). Baseline: `max_subcompactions=1` on 1-DB/16-DB runs with 1-writer/warm-read controls.
   - **Test & rule:** Add an `L0->L1` test checking `PARALLEL_SUB_COMPACTIONS_TAKEN`, sub-range pruning of point-disjoint L0 SSTs (keeping global `collect_range_fragments`), and serial-output parity across crossing tombstones, snapshots, and racing flushes; add a shared worker-permit pool. **Pass** if 5-pair median stall time or write p99 beats baseline beyond IQR on 1-DB/16-DB runs; **defer** otherwise.

4. **Bound grouped point-read claims and separate page cache from cold I/O**
   - **Target:** `## 5. Promote only the candidates supported by the profiles`; `ReadState::point_lookup` ([read.rs](../../../../src/db/read.rs#L37-L118)), `BlockCache::get_cached_block` ([block_cache.rs](../../../../src/cache/block_cache.rs#L386-L395)).
   - **Hypothesis:** Grouping keys on one `SuperVersion` trims metadata probes for co-located keys, whereas synchronous `pread` cannot overlap multi-block disk I/O.
   - **Baseline/control:** Scalar `get_pinned_with_options` loop reusing *one* `Snapshot` (avoiding per-key snapshot-lock bias). Shrinking `BlockCachePool` alone is an **invalid cold baseline** as SSTs stay in OS page cache.
   - **Test & rule:** Build a 1/8/32-key driver and block-read counter across warm `BlockCache`, warm page cache (`BlockCache` disabled), and cold storage (`posix_fadvise(..., POSIX_FADV_DONTNEED)`) for clustered and uniform keys. **Pass** only if grouped reads beat the single-snapshot loop beyond 5-pair IQR without extra pinned-block retention; **defer** otherwise.
